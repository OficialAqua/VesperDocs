# VesperClient

## Papel

Plugin client-side opcional para qualidade de vida, chat e futuras interfaces Vesper.

## Repositório

[OficialAqua/VesperClient](https://github.com/OficialAqua/VesperClient)

## Estado confirmado

A branch `develop` prepara a versão 0.3.0 Stable com:

- histórico;
- cópia de mensagens;
- autocomplete Vesper;
- nomes observados;
- comandos VCF dinâmicos.

Banners e VesperBuild permanecem no código, mas estão excluídos da compilação Stable.

## Fronteiras

- Nunca obrigatório para entrar no servidor.
- Nunca fonte de autoridade.
- Falhas devem preservar o chat/jogo original.
- Não usar o chat como transporte técnico.
