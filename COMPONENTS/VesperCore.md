# VesperCore

## Papel

Plugin server-side principal para sistemas próprios do Domínio Escarlate.

## Repositório

[OficialAqua/VespelCore](https://github.com/OficialAqua/VespelCore)

## Estado confirmado

O GitHub contém uma base modular histórica com Bootstrap, configuração, serviços, event bus e módulos para Announcement, Bloodcraft, Events, Houses e Prestige. Não contém ainda toda a fonte da build operacional conhecida.

## Fronteiras

- Não depender obrigatoriamente do VesperClient.
- Manter autoridade, eventos e persistência no servidor.
- Testar mudanças no servidor Development/Test.
